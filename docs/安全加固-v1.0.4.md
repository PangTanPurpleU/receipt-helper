# 安全加固 v1.0.4

针对 2026-10-22 安全排查中的文件处理问题进行加固。

- ZIP 取消整包并行 CRC 解压，改为顺序读取实际输出块，超过声明大小、单文件上限或总量上限即拒绝；CRC32 与照片 SHA-256 校验保留。
- 路径、文件种类和记录引用先验证，拒绝不受支持的额外文件后再读取照片。
- 浏览器中的备份检查在独立 Worker 中完成，90 秒未完成会终止线程，验证成功后才进入原有原子恢复事务，并再次比较恢复前的数据快照。
- 图片检查文件头中的格式和尺寸，再调用解码器；限制 30 MB、2400 万像素、单边 12000 像素。支持 JPEG、PNG、静态 WebP、常见 BMP，以及能在前 1 MB 头部验证尺寸的 HEIC/AVIF。无法验证的文件明确提示转换格式。拒绝 SVG、HTML、GIF、动画 WebP 等不支持的输入，扩展名和传入 MIME 不能绕过检查。
- 图片解码增加 20 秒等待限制、解码后尺寸复核及超时后迟到 Bitmap 释放。浏览器原生解码不具有硬内存隔离，不能据此承诺能防御所有损坏图片或浏览器自身解码漏洞。
- 导入和恢复均保留原始照片字节及 SHA-256，仅按检验结果赋予 MIME；历史照片在详情展示前也检查。旧版 ZIP 格式兼容，但照片同样须满足新的格式、尺寸上限。
- 恢复 Worker 纳入离线外壳缓存及版本摘要；添加无 Referer 的页面策略，备份成功提示说明 ZIP 未加密。

没有改动数据库名/版本、正式域名、原有照片保留策略或增加密码加密。删除原图、备份加密与跨域迁移需要单独设计，不能宣称本次已完成这些功能。

验证：

- 完整构建及 136 项测试通过，包括新增的伪装格式、超大尺寸、压缩包实际输出、CRC、拒绝时数据保留，以及 Worker 超时/异常终止。
- 实际浏览器：DEFLATE 格式旧备份成功恢复；伪装 PNG 的无脚本 HTML 被拒绝，原有一条凭证和金额保留；伪造解压长度的 1 MB 合成 ZIP 被拒绝，原数据保留。
- 合成中文 PNG 经真实 OCR 导入成功，金额 12.00、交易时间及单号被提取，并正确与恢复记录判重。
- 停止本地 HTTP 服务后刷新，离线主页、模型状态、STORE 格式备份恢复均成功；详情原图实际解码尺寸 1000 × 1400。测试使用独立的 localhost:8097 环境，没有向正式网站导入测试凭证。
