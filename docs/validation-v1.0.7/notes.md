# v1.0.7

统计区恢复纯色 surface，取消渐变。搜索默认显示 44px 放大镜按钮；点击后从按钮位置揭开输入框，采用 CSS clip-path 200ms 与 opacity 160ms，复用 ease-out。收起沿相反路径返回，不动画宽高，不增加依赖。减少动画偏好下直接切换。
