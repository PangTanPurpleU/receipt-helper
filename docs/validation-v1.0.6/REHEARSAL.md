# 界面优化 v1.0.6

使用 stageshow 的层级、留白、表单反馈原则优化真实应用。参考 craft.md 与 form-error 示例；没有把演示用占位行、模拟光标或 React 演示组件接入正式工具。

设计：金额是视觉重点，数量与模型状态作为辅助；凭证记录区承接搜索、筛选、导入；桌面常用操作直接显示，窄屏收回菜单。保留原有图标和系统字体。

实施：统计面板、模型状态、凭证列表、空结果、选中状态、详情分区和密码校验反馈。新增商户/金额/单号搜索和清除按钮，数量显示当前结果/总数。复用已有搜索与筛选函数，查重证据和金额算法未改动。

验证：142 项测试通过；本机合成凭证搜索未匹配时为 0/1，清除后恢复 1/1；桌面快捷备份打开密码弹窗；密码不一致聚焦确认框并标记 aria-invalid，修改后清除。390×844 布局 document.scrollWidth=390，无横向溢出，截图见 mobile.png；desktop.png 为默认桌面宽度。没有进行真实手机硬件验证，没有新增循环演示动画，因此没有 stageshow 的影片门禁记录。数据操作未对正式库执行。
