# 完整网站包使用说明

## 包内内容

- `dist/`：可直接部署的完整网站，包含网页、图标、PWA、OCR Worker、模型和 ONNX Runtime WASM。
- `src/`、`public/`、`assets/`、`tools/`：完整项目源码、原始模型、构建/测试/预览/打包工具。
- `package.json`、`pnpm-lock.yaml`、`pnpm-workspace.yaml`：锁定的开发依赖。
- `.github/workflows/pages.yml`：持续构建、测试和发布工作流。
- `.git/`：独立完整的 Git 仓库，保留可达提交历史、分支、标签和 origin 远程地址；无需重新 git init。
- `docs/`：代码说明、部署说明、各轮验证记录。
- `legal/`、`dist/THIRD_PARTY_LICENSES.txt`：第三方许可与来源。
- `release.json`、`SHA256SUMS.txt`：源码提交版本、生成时间、逐文件校验值。

不包含私人凭证、浏览器数据或 `node_modules`。Git 元数据来自独立克隆，不包含本机 Git 凭据、原仓库自定义钩子或 reflog。已构建的网站可直接使用，开发依赖可依锁文件重新安装。

## 本机使用已构建网站

先安装 Node.js 24 LTS。在解压目录执行：

```sh
node tools/serve.mjs
```

保持终端打开，在浏览器访问 `http://127.0.0.1:8080/`。Mac 可以打开根目录的 `启动本地预览.command`，Windows 可以打开 `启动本地预览.cmd`；这两个快捷方式也要求系统已有 Node.js。端口被占用时运行：

```sh
node tools/serve.mjs --port 8081
```

不能直接双击 `dist/index.html` 以 `file://` 运行。模块、Worker、WebAssembly、Service Worker 需要 HTTP 的 localhost 或 HTTPS 环境。本机预览只监听 127.0.0.1，不对局域网开放。

第一次点击“下载识别模型”时，浏览器从包内本地服务器读取模型并缓存，并非向外部上传照片。完整包已经包含模型，无需额外寻找模型下载地址；模型准备好后可在同一浏览器、同一网址使用离线资源。

## 继续开发

安装 Node.js 24 LTS 和 pnpm 11.25.0 后：

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test
node tools/serve.mjs
```

首次开发安装依赖需要访问包注册表。运行预先构建的 `dist/` 不需要安装这些项目依赖。Node.js 本身未随包分发。

请勿手改 `src/model-assets.js` 或 `dist/sw.js` 的校验值；构建工具会依据模型和资源内容自动生成。

## 发布正式网站

将 `dist/` **里面的全部文件和子目录**上传到支持 HTTPS 的静态网站服务，保留 `.nojekyll`，保持模型和 WASM 路径完整；不需要服务端 OCR、数据库、密钥或付费 API。也可使用 GitHub Pages：将源项目推送到 main，仓库 Pages 来源选择 GitHub Actions，由包内工作流构建发布。

如果新增网址、端口或域名，原网址凭证不会自动出现。请先在旧网址“更多操作 → 备份当前凭证”，再到新网址“恢复备份”。浏览器下载的备份完成并不意味着操作系统已永久保存，请检查下载文件。

## 检查压缩包内容

`SHA256SUMS.txt` 覆盖包内业务文件和 `release.json`，不包含其自身。Mac/Linux 可在解压后的项目根目录运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

再次生成交付包：在一个 Git 仓库内完成并提交所需源码，先构建与测试，再执行：

```sh
node tools/package-release.mjs /绝对路径/查重小助手-网站完全体.zip
```

打包工具只包含 Git 已跟踪、且位于源码允许清单内的文件，以及 `dist/` 和生成的模型资源清单。新增源码须先加入 Git；交付包包含独立的 `.git/`，解压后可直接运行 `git log`、`git branch -a`、`git remote -v` 和 `git status`。推送时使用自己的 GitHub 登录凭据，不随包分发认证信息。所有真实测试照片和本机配置都不进入交付包。Git 数据不依赖本机原始仓库路径，解压后可独立使用。
