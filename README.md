# 查重小助手

网站入口：https://pangtanpurpleu.github.io/receipt-helper/

免费的浏览器本地凭证 OCR、查重与 Excel 导出工具，适配 iPhone Safari 和桌面浏览器。

照片、识别文字和凭证记录只保存在当前浏览器，不上传、不同步。PaddleOCR v6 tiny 是唯一识别模型，在浏览器 Worker 中免费运行。首次下载约 30 MB（含共用运行库），已有 tiny 资源可继续复用。完整下载后显示紧凑的绿色就绪状态栏；未下载时显示下载卡片。已下载资源支持离线识别，缓存被浏览器清理后需重新下载。

2026-10-14 用户在手机上使用 v6 tiny 测试 46 张照片，反馈均正确且速度快，因此移除 v5 mobile 和 v6 small。请继续核对金额和长单号。页面突出金额统计与凭证列表，筛选栏保留全部、重复、待核对。长按凭证进入多选并自动选中该张，随后点击切换选中状态；取消最后一张、取消全选或删除所选后退出多选。确认删除后只从网页列表永久移除识别记录，保留浏览器照片副本，手机相册原图不受影响。

## 功能

- 支付凭证及转账电子凭证识别、字段核对、重复依据展示。
- 筛选、长按多选与确认后仅删除凭证识别记录。
- Excel 导出：交易时间、金额、收款方、交易/转账单号、是否重复；按交易时间排序，顶部统计总金额，重复标红。
- ZIP 本地备份、恢复及恢复前备份。
- 移动端布局、深色模式、减少动态效果适配、添加到主屏幕。

## 开发与部署

使用 Node.js 24 和 pnpm 11.25.0，在本目录执行：

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test
```

仅发布构建生成的 `dist/`。模型位于 `assets/models/`，构建时会生成文件大小与 SHA-256 清单；第三方许可随网站一起输出。页面和模型路径均为相对路径，支持 GitHub Pages 项目子路径。

GitHub Actions 在推送 `main` 时自动构建、测试并发布 GitHub Pages。发布权限限定在部署任务，不需要保存个人访问令牌。此仓库不包含真实凭证、私人研究数据或登录配置。

维护约定：项目所有者已授权在修改完成、构建及相关验证通过后直接发布到上述网站，供手机查看验收。发布后应确认 GitHub Actions 部署成功和线上页面更新。

## 从旧网址迁移本地凭证

不同网址的浏览器存储互相独立。请在旧网站通过“更多操作”导出 ZIP 备份，保存到设备，再在新网站通过“恢复备份”导入。新网址需要单独下载识别模型；迁移网站不会自动复制旧网址的本地数据。
